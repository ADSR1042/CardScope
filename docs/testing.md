# 验证报告

验证日期：2026-09-18。所有模拟数据与本机真实采集数据使用独立数据库。

## 已通过：本机实测

环境为 Ubuntu 22.04.5 / WSL2、普通用户（UID 1000）、GTX 1050 2 GB、驱动 582.66。没有使用 sudo，没有修改显卡驱动或执行 GPU 压力测试。

| 项目 | 结果 |
| --- | --- |
| NVML 动态加载、显卡枚举、UUID / PCI 地址 | 通过 |
| 利用率、显存总量/使用量、温度 | 读取成功，与本机显卡对应 |
| 功耗与 ECC | 驱动返回不支持，保存为 null，页面显示不可用 |
| GPU 用户归属 | WSL 限制明确显示，未把空进程列表解释为空闲 |
| CPU、内存、网卡、磁盘 | 普通用户读取并展示 |
| 客户端配置 | Linux 权限为 0600 |
| 客户端到中心上报 | 通过，仅客户端发起连接 |
| 独占运行锁 | 第二个相同配置的客户端被拒绝 |
| 断网缓存与恢复 | 暂停测试中心后产生 2 个缓存样本，恢复后均补传并各入库一次 |
| 中心重启 | 账号、节点凭据、历史记录保留 |

Windows 挂载目录中直接覆盖已运行的 Linux 二进制曾导致 WSL 读取旧映射异常；验证脚本已改为复制到 WSL 原生目录中的独立版本路径后运行。实际部署也建议先停止旧进程，再替换发行文件。

## 已通过：自动化逻辑与接口测试

Go 测试覆盖：

- 未登录不可查看数据，节点凭据不能读取面板或上报其他节点。
- 团队只读账号不能修改，写请求需要 CSRF，跨来源写请求被拒绝。
- 一次性接入码有效期、重复兑换拒绝、并发兑换仅一次成功。
- 撤销凭据立即生效；修改密码会使对应会话失效。
- 登录限速、安全响应头、CSV 公式转义。
- 同一卡多进程去重、多人共享分别计时、不同 GPU 独立积分。
- 重复和乱序上报不重复累计，并修正相邻积分区间。
- 超长采样缺口、客户端重启、权限不足与空指标不填零。
- 未知用户降低归属覆盖率，但保留可确定的整卡占用。
- 趋势缺失桶返回 null，图表不跨缺口连线。
- 显卡消失后保留卡片；过期事件清理。
- GPU 疑似空闲需要所有必要指标有效；显存占用较高、WSL 受限或利用率未知均不判空闲。

12 项 Go 测试通过；其中 10 项后端测试另外编译为 Linux 测试程序并在 WSL 运行通过。Linux 目标 `go vet` 通过。

20 台、160 张 GPU、480 个 GPU 观测的模拟入库测试通过。在本机 Windows 测试运行中耗时约 93 毫秒，WSL 测试运行中约 229 毫秒；这是小批量测试数据，不代表长期吞吐承诺。

## 尚未实机验证及明确限制

- 原生 Linux 上跨真实用户的进程可见性、容器 PID 映射、多卡硬件故障。
- ARM64 驱动及 NVML 实机兼容性。
- MIG/MPS 精确用户归属、RDMA 流量、不同型号的算力折算不在第一版能力内。
- 无长期 20 台生产负载实测，保留策略以单元测试和短期运行验证。
- 未修改 linger，也未安装常驻用户服务；WSL 关闭后本机测试服务不会自动恢复。可重新运行 WSL 验证脚本恢复测试面板。
- HTTP 仅提供访问认证，不提供传输加密，按受控内网部署。
- 用户持卡时间是采样观测数据，不作为计费依据。

- 回归测试通过：预先取消、采样中取消、正常采集失败继续心跳、失败不误报缺卡、不沿用旧指标、统计跳过失败区间、真正缺卡仍记录。
